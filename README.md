# Clockin for Mac

Downloads and the update feed for Clockin for Mac. The source is in
[erdmncdr/clockin-ios](https://github.com/erdmncdr/clockin-ios), which builds
both the iPhone and the Mac app.

**Download:** [Clockin.dmg](https://github.com/erdmncdr/clockin-macos/releases/download/macos-updates/Clockin.dmg)
(always the latest version), or from [getclockin.netlify.app](https://getclockin.netlify.app).
Open the DMG and drag Clockin into Applications. Requires macOS 14 or later,
Apple Silicon or Intel. The app and the DMG are Developer ID signed and
notarized by Apple.

Installed copies update themselves through the signed feed in the
`macos-updates` release. Each version is also a release of its own,
`macos-v<version>`.

Clockin 2.0.9 and earlier read their updates from an address that no longer
works. Install 2.0.10 or later once from the link above; updates come through
the app after that.
